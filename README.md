# مسجّل صوت اجتماعات Google Meet 🎙️

تطبيق سطح مكتب مبني بـ **Electron + Node.js** يقوم بالانضمام إلى اجتماع
**Google Meet** تلقائيًا عبر **Puppeteer**، وتسجيل **الصوت فقط**، ثم رفع ملف
التسجيل إلى **Google Drive**، مع التزام كامل بـ **معايير إمكانية الوصول**
ودعم **قارئات الشاشة**.

---

## ✨ المزايا

- إدخال رابط اجتماع Google Meet والانضمام إليه تلقائيًا.
- خياران للتشغيل:
  - **بدء التسجيل فورًا**.
  - **جدولة** وقت البدء و/أو وقت الانتهاء تلقائيًا.
- تسجيل **الصوت فقط** بصيغة `WebM/Opus` (بحجم صغير وجودة عالية).
- تشغيل المتصفح **مرئيًا أو في الخلفية** (headed / headless).
- رفع تلقائي إلى Google Drive (مع دعم تحديد مجلد هدف).
- **واجهة متوافقة مع قارئات الشاشة**:
  - سمات `role` و`aria-label` و`aria-describedby` على كل العناصر.
  - مناطق مباشرة `aria-live` للإعلان عن الحالات (`role="status"`).
  - منطقة تنبيه فوري للأخطاء (`role="alert"`).
  - تنقّل كامل بلوحة المفاتيح (Tab / Enter / Space) مع مؤشّر تركيز واضح.
  - رابط "تخطَّ إلى المحتوى الرئيسي" ورؤوس هيكلية صحيحة.

---

## 📦 المتطلبات الأساسية

1. **Node.js** إصدار **18** أو أحدث — [التنزيل](https://nodejs.org).
2. **متصفح Chrome** مثبّت على الجهاز (اختياري: يستخدم التطبيق Chromium
   المُرفَق مع Puppeteer تلقائيًا إن لم يوجد Chrome).
3. **حساب Google** ومشروع في **Google Cloud Console** (لتفعيل رفع Drive).

## 🚀 خطوات التثبيت والتشغيل (خطوة بخطوة)

### 1) تثبيت الاعتماديات

افتح الطرفية (Terminal / PowerShell) داخل مجلد المشروع ثم نفّذ:

```bash
npm install
```

> سيقوم هذا الأمر بتثبيت `electron` و`puppeteer` و`puppeteer-stream`
> و`googleapis`، وتنزيل نسخة Chromium خاصة بـ Puppeteer.

### 2) إنشاء بيانات اعتماد Google Drive (OAuth 2.0)

1. اذهب إلى [Google Cloud Console](https://console.cloud.google.com/).
2. أنشئ مشروعًا جديدًا (أو اختر مشروعًا موجودًا).
3. من القائمة، اختر **APIs & Services → Library** ثم فعّل
   **Google Drive API**.
4. اذهب إلى **APIs & Services → OAuth consent screen** وأكمل الإعداد
   (اختر `External`، وأضف بريدك في **Test users**).
5. اذهب إلى **APIs & Services → Credentials → Create Credentials →
   OAuth client ID**.
6. اختر نوع التطبيق **Desktop app**، ثم أنشئه.
7. اضغط **Download JSON** لتحميل ملف `credentials.json`.

### 3) توفير بيانات الاعتماد للتطبيق (طريقتان)

**الطريقة الأولى (الأسهل):** شغّل التطبيق ثم اضغط زر
**«استيراد ملف بيانات الاعتماد»** واختر ملف `credentials.json`.

**الطريقة الثانية:** انسخ الملف `.env.example` إلى `.env` وضبط القيم:

```bash
copy .env.example .env      # على Windows
cp .env.example .env        # على macOS / Linux
```

ثم عدّل `.env`:

```env
GOOGLE_CLIENT_ID=xxxxxxxx.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=xxxxxxxx
```

> يمكنك أيضًا وضع ملف `credentials.json` يدويًا داخل مجلد بيانات المستخدم
> الخاص بالتطبيق (يظهر مساره في سجل الأحداث).

### 4) تشغيل التطبيق

```bash
npm start
```

عند أول عملية رفع، سيُفتح المتصفح تلقائيًا لتفويض الوصول إلى Google Drive
(اضغط «الاتصال بحساب Google» أولًا إن أردت التفويض مبكرًا). يُحفظ التفويض في
`token.json` لإعادة استخدامه لاحقًا.

## 🖱️ طريقة الاستخدام داخل التطبيق

1. ألصق رابط الاجتماع في خانة **«رابط اجتماع Google Meet»**.
2. (اختياري) اكتب الاسم الظاهر، وحدّد **تشغيل المتصفح في الخلفية**.
3. اختر طريقة البدء:
   - **بدء التسجيل فورًا**، أو
   - **جدولة وقت البدء والانتهاء** ثم حدّد التوقيتين.
4. تأكد من خيار **«رفع التسجيل تلقائيًا»** إن أردت الرفع إلى Drive.
5. اضغط **«ابدأ التسجيل»**، وتابع الحالة في قسم **«حالة التطبيق»**.
6. لإيقاف التسجيل مبكرًا اضغط **«أوقف التسجيل»**.

> يتم حفظ التسجيلات في مجلد `recordings` داخل مجلد بيانات المستخدم،
> ويمكنك فتحه بزر **«فتح مجلد التسجيلات»**.

## ⚠️ ملاحظات مهمة وحدود تقنية

- **الموافقة القانونية**: تسجيل الاجتماعات قد يتطلب موافقة جميع المشاركين
  وفقًا للقوانين والسياسات المعمول بها. استخدم التطبيق بمسؤولية.
- **تغيير واجهة Google Meet**: تعتمد خطوات الانضمام على مُحدّدات (selectors)
  لعناصر الواجهة. إذا غيّرت Google هذه العناصر مستقبلًا، فقد تحتاج إلى تحديث
  الدوال `_joinMeeting` و`_waitForAdmitted` داخل `src/automation/meetRecorder.js`.
- **الاجتماعات التي تتطلب تسجيل الدخول**: بعض الاجتماعات لا تسمح بالدخول
  كضيف. في هذه الحالة يجب تسجيل الدخول مسبقًا (يمكن استخدام `userDataDir`).
- **التسجيل الصوتي فقط**: يتم تجاهل الفيديو تمامًا لتقليل حجم الملف؛ يعتمد
  التقاط الصوت على مكتبة `puppeteer-stream`.
- **headless على Windows**: قد تتأثّر دقة الالتقاط في الوضع المخفي؛ يُفضّل
  الوضع المرئي (headed) إذا واجهت مشاكل.

## 🔧 استكشاف الأخطاء

| المشكلة | الحل المقترح |
| --- | --- |
| `puppeteer-stream غير مثبّتة` | نفّذ `npm install` داخل مجلد المشروع. |
| لا يتم التقاط الصوت | تأكّد من عدم تمرير `--mute-audio`، وأن المتصفح يُشغّل الصوت أثناء الاجتماع. |
| فشل الرفع | أعد الاتصال بزر «الاتصال بحساب Google»، وتأكّد من تفعيل Drive API. |
| تعذّر إيجاد زر الانضمام | حدّث المُحدّدات في `meetRecorder.js` (قد تكون Google غيّرت الواجهة). |
| خطأ في المنفذ `42813` | أغلق أي تطبيق يستخدم المنفذ، أو غيّر `REDIRECT_PORT` في `googleAuth.js`. |
